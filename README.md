# Những Ngày Chậm Lại

Trang giới thiệu sách tĩnh, responsive, được xây dựng với Bootstrap 5.3:

- Header/navbar và Book Overview
- Author
- Features
- Prices
- Download chương đọc thử (`sample-chuong-1.txt`)
- Reader's Say
- Footer

Mở `index.html` trong trình duyệt. Bootstrap CSS/JavaScript được tải từ jsDelivr CDN, nên cần kết nối Internet để hiển thị đầy đủ.

Tên sách, tác giả và nội dung là sản phẩm hư cấu được tạo riêng cho bài thực hành. Các phản hồi độc giả, giá bán và liên kết đặt sách chỉ mang tính minh họa.
